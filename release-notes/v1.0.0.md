# WGRALGO Financial Fraud Detective — v1.0.0

First official public GitHub release of the WGRALGO Financial Fraud Detective Android APK.

## What's new

- Offline fraud-detection educational game
- 10-case sessions drawn at random from a 100+ case pool
- Beginner / Intermediate / Advanced difficulty levels
- Case categories: text, message, phone call, email, investment offer, payment app, job offer, bank alert
- Two-button gameplay: Fraud or Looks Legit
- Instant feedback with red-flag explanations and protective tips
- Scoreboard, progress tracking, and Play Again
- Final detective rating (Master Fraud Detective → Needs More Case Work)
- WGRALGO black-and-gold UI, phone and tablet responsive
- Proper release signing
- No `INTERNET` permission requested
- GPLv3 licensing, privacy statement, contributors file, security policy, and README

## Install

1. Download `WGRALGO_Financial_Fraud_Detective_v1.0.0.apk` from this release.
2. (Optional) verify:
   ```
   sha256sum -c WGRALGO_Financial_Fraud_Detective_v1.0.0.apk.sha256
   ```
3. Allow install from unknown sources for your browser/file manager.
4. Open the APK and install.

If you previously installed any test/debug build, uninstall it first before installing v1.0.0.

## Disclaimer

Financial Fraud Detective is for educational awareness only. It does not provide legal, financial, banking, cybersecurity, or fraud-investigation advice. If you believe you are the victim of fraud, contact your financial institution, relevant authorities, or a qualified professional.
