Financial Fraud Detective v1.1.0 brings the new case library from the updated web game and a new app design. Like v1.0.0, it works offline and is free, with no ads, account, analytics, trackers, subscription, or cloud. The App ID (org.wgralgo.financialfrauddetective) is unchanged, and the app has no INTERNET permission.

## ⚠️ Uninstall v1.0.0 first
This release is signed with a **new WGRALGO release key**. Android will not install it over v1.0.0. If you have v1.0.0 installed, **uninstall it first**, then install this one. The app doesn't store accounts or personal data, so uninstalling loses nothing. Future updates will install over v1.1.0 normally.

## What's new
- **45 realistic cases** on money traps that go beyond everyday scam texts: identity theft, cars, contractors, loans, credit and debt, taxes, benefits, immigration and legal help, cards and checks, home and property, and small business.
- **Evidence as you'd really see it:** text threads, emails (with the real link behind the button), phone-call transcripts, web pages, mailed letters, and in-person situations.
- **Balanced rounds:** each round has 10 cases (4 beginner, 4 intermediate, 2 advanced), with 5 fraud and 5 legit, so guessing "fraud" every time won't work.
- **Better feedback:** after each answer you get the red flags (or why it checks out) and **what to do in real life**.
- **Results:** detective rank, your weak spots by category, and an expandable case file of every answer.
- **New app design:**
  - top app bar with a back button and a live score
  - a progress bar
  - fixed bottom buttons sized for thumbs
  - a results screen with a score ring
  - About, Privacy, and Credits in slide-up sheets
- Version 1.0.0 → 1.1.0 (versionCode 100 → 110).
